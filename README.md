# To Do App – letöltés / Download

Feladatkezelő Windowsra és Androidra, szinkronizálással.
A to-do app for Windows and Android, with sync.

## Letöltés / Download

A legfrissebb verzió: **[Releases → Latest](https://github.com/orsimarcell/todo-app-releases/releases/latest)**

| | Fájl / File |
|---|---|
| Windows (telepítő / installer) | `ToDoApp-Setup-<verzió>.exe` |
| Windows (telepítés nélkül / portable) | `ToDoApp-windows-<verzió>.zip` |
| Android | `ToDoApp-android-<verzió>.apk` |

### Telepítés

**Windows:** futtasd a `ToDoApp-Setup-….exe`-t. Nem kell hozzá rendszergazdai jog,
frissítéskor az adatok megmaradnak. Ha a Windows SmartScreen figyelmeztet
(a telepítő nincs tanúsítvánnyal aláírva): „További információ” → „Futtatás mindenképp”.

**Android:** nyisd meg az APK-t a telefonon, és engedélyezd a telepítést ebből a
forrásból (böngésző / Fájlok), ha a telefon rákérdez.

### Installing

**Windows:** run `ToDoApp-Setup-….exe` (no admin rights needed; updates keep your
data). If SmartScreen warns (the installer is not code-signed): "More info" →
"Run anyway".

**Android:** open the APK on the phone and allow installing from that source if asked.
